Place the permanent Excel master files in this folder before pushing/deploying to GitHub:

1. MedDRA.xlsx
   - Used for LLT-PT mapping.
   - Expected columns include: LLT Code, LLT Term, PT Term, etc. as used by the app.

2. Listedness_CX.xlsx
   - Used for listedness assessment.
   - Required columns: Drug Name, LLT

The app also accepts .xlsm and .xls variants, but .xlsx is recommended.
